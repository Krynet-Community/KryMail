## 📖 About

**KryMail** was originally envisioned as an integrated mail service for the Krynet ecosystem.

The idea was publicly discussed during Krynet's development and was intended to become an official component of the platform. However, the project never progressed beyond the concept stage and was ultimately abandoned before development began.

This repository preserves that idea as an open-source community archive.

---

## 🎯 Purpose

This repository exists to:

* 📬 Preserve the original KryMail concept
* 📚 Document the project's history
* 🧪 Explore community implementations
* 💡 Experiment with alternative approaches
* 🤝 Give developers a starting point if they wish to continue the idea independently

Nothing in this repository represents Krynet's current roadmap or future plans.
